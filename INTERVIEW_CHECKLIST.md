# Interview Checklist

Use this checklist the day before or the hour before the interview.

## Last 60 minutes

- Re-read `module05constructs/IfElseAndEOP.scala`
- Re-read `module07collections/SequenceMethods.scala`
- Re-read `module10functions/PureFunctions.scala`
- Re-read `module12domainfp/EitherBasics.scala`
- Re-read one project from `module13projects`

## Must be able to explain clearly

- `val` vs `var`
- `List` vs `Vector`
- `map` vs `flatMap` vs `foldLeft`
- `Option` vs `Either` vs `Try`
- class vs case class
- trait vs inheritance
- enum vs sealed trait
- pure function vs impure function
- closure vs partially applied function vs curried function
- immutable domain data vs stateful service

## Whiteboard or live-coding readiness

- Write a small `case class`
- Write a small `sealed trait` ADT
- Write a safe validator returning `Either`
- Transform a list with `map`, `filter`, `flatMap`
- Aggregate a list with `foldLeft`
- Model a tiny workflow with states and transitions

## Final communication reminder

Explain trade-offs, not only syntax.
Say what you would choose, why you would choose it, and what problem it prevents.
