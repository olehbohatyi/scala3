# Module 24 — Capstone Projects

Combines Scala 3 features into compact, interview-ready final projects.

## Files

| File | Topic |
|------|-------|
| `ContextAwareJobBoard.scala` | Givens, context functions, smart constructors, and exports |
| `TypedOrderSystem.scala` | Opaque types, enums, extension methods, and ADTs |
| `CompileTimeDiagnostics.scala` | Inline and metaprogramming-inspired validation helpers |
| `Scala3FeatureTourApp.scala` | A compact app that stitches multiple Scala 3 features together |

## Run

```bash
scala-cli run module24capstone/
```

## Goal

These projects are intentionally compact, but each one combines multiple Scala 3 concepts in one runnable program.
